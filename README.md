# RD Quiz

A mobile quiz game: celebrity quizzes, general knowledge and much more. How many can you answer?

- 25 quizzes + Random Mix + True or False
- 3 levels per quiz (Easy 15s, Medium 10s, Hard 5s)
- Points, streaks, stars, best scores saved on device
- 5 languages: English, Kreyòl Ayisyen, Français, Español, Português

Open `index.html` in a browser to play, or enable GitHub Pages (Settings → Pages → Deploy from branch, `main`, `/ (root)`).
